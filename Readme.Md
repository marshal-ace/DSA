## 🚀 Launch Sequence — How to Run

### Prerequisites

- Python 3.8 or above
- No external libraries required (pure Python solutions)

### Clone the Repository

```bash
git clone https://github.com/gauthamseeram/<your-repo-name>.git
cd <your-repo-name>
```

### Run Any Solution

```bash
python <topic-folder>/<problem-file>.py
```

**Example:**

```bash
python Arrays/two_sum.py
```
